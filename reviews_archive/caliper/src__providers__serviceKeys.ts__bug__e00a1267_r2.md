## Verdict
Shippable — the registry's structure, type guard, and cross-file lockstep (stores map, PROBES record, test-pinned id list) all trace clean. The single new defect is staleness: two of six hint strings tell the owner "adapter to come" for adapters that are now live and spending-capable, which breaks the repo's own truthfulness rule in a money-spending app.

## Bugs & vulnerabilities
- **[MEDIUM] Stale hints claim live money-spending adapters are "to come"** - `line 17`, `line 20` (with `line 3-4`)
  - What: The OpenRouter row says "the optimizer's cloud brain (adapter to come)" and the EachLabs row says "cloud generation - 500+ models, one API (adapter to come)". Both adapters have shipped and are mounted live middleware: OpenRouter cloud video generation exists in `vite.openrouter.ts:1-8` (per-second billed POST /videos pipeline) and serves as the optimizer's default brain in `vite.llm.ts:24`; EachLabs model listing and generic cloud runs exist in `vite.eachlabs.ts:29-58` (/models, /run) and are consumed by the film autopilot (`vite.film.ts:268`, `:427`, `:999`). The header comment at `line 3-4` still asserts "the hints say plainly which services have adapters still to come" — a mechanism that now emits false statements for 2 of 6 services. The file was last touched 2026-08-22 (Wave 3, commit 3fe3a83); the adapters landed after and the hints were never revisited.
  - Trigger: Open the settings window — `vite.keys.ts:77` GET /api/keys spreads each `ServiceKeyDef` verbatim, `src/api/keys.ts:15` returns it, and `src/components/SettingsConsole.tsx:164` renders `{k.hint}` in every key row. Always reproducible; no state required.
  - Impact: The owner is told a stored OpenRouter/EachLabs key has no consuming adapter yet, while the film autopilot and the LLM brain can already spend real money through those exact keys — a truthful-status violation in the surface that governs key entry. At minimum it misleads paste/no-paste decisions for the two services the film pipeline bills through.
  - Fix: Update the two hint strings to describe the live role (e.g. openrouter: per-second cloud video + the optimizer brain; eachlabs: the picker's second cloud shelf / generic cloud runs) and reword the header's "still to come" framing so it no longer over-promises what the hints track.
